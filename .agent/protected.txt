# Protected paths — read by scripts/agent_guard.py.
# The copy on your BASE branch is the one CI enforces (.github/workflows/guard.yml), so a PR
# can't loosen these rules for itself.
#
#   locked <glob>     agents may not add, edit or delete            → label `allow-protected`
#   immutable <glob>  existing files (on base) can't be edited or deleted; new files are fine
#                                                                    → label `allow-protected`
#   review <glob>     existing files may be edited, but a human must look
#                     (locally: you get a prompt; in CI: label `human-reviewed`)
#
# Files a branch created itself are never "existing" — agents can freely edit their own new
# tests and new migrations until they merge.
#
# Globs: `*` matches across directories; a leading `**/` also matches at the repo root.
# Strictest matching tier wins.
